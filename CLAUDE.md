# CLAUDE.md

Инструкции для Claude Code по ведению проекта «Планировщик для Битрикс24».
Общее описание возможностей — в `README.md`.

## Суть проекта

Календарь-планировщик, встраиваемый в портал Битрикс24 (placement-приложение).
Недельная сетка ПН–ПТ 8:00–18:00, шаг 30 минут, до 5 сотрудников колонками.
Работает с задачами, встречами и отсутствиями через REST API Битрикс24.

Чистый JavaScript (ES-модули), **без сборщика и npm-зависимостей**. Не добавлять
фреймворки, `package.json` и сторонние библиотеки без явной просьбы.

## Структура

- `index.html` — точка входа для модульной версии (подключает BX24 SDK).
- `css/styles.css` — все стили.
- `js/config.js` — константы: режим транспорта, сетка (`GRID`), цвета, статусы задач.
- `js/dates.js` — даты и RU-форматирование.
- `js/recurrence.js` — правила повторения: `rrule` для календаря и разворачивание
  серии задач (каждое повторение — отдельная задача, не более `RECUR_MAX_TASKS`).
- `js/b24.js` — транспорт (BX24 SDK / шлюз vibecode), ретраи, batch, опции приложения.
  Весь сетевой контракт — только здесь.
- `js/data.js` — доменный слой: загрузка/сохранение, маппинг ответов REST в модель item.
- `js/state.js` — состояние + перерисовка; `js/bus.js` — мост без циклических импортов.
- `js/app.js` — bootstrap и связывание UI.
- `js/ui/*` — `calendar.js` (сетка и блоки), `employees.js` (мультиселект, настройки),
  `modals.js` (меню слота и формы), `tooltip.js`, `toast.js`.
- `tools/build-singlefile.mjs` — сборка единого файла.
- `dist/index.html` — **генерируемый** артефакт для хостинга vibecode.

## Рабочий процесс

1. Правки делать только в исходниках `js/`, `css/`, `index.html`.
   `dist/index.html` руками не редактировать.
2. После любых правок пересобрать единый файл:
   ```
   node tools/build-singlefile.mjs
   ```
   и закоммитить обновлённый `dist/index.html` вместе с исходниками.
3. Новый JS-модуль нужно добавить в `MODULE_ORDER` в `tools/build-singlefile.mjs`
   с учётом зависимостей. Сборщик вырезает `import`/`export` построчно: импорты
   писать с `;` в конце, все модули делят одну область видимости, поэтому
   имена верхнего уровня не должны пересекаться между файлами.
4. Проверка: `node --check` для изменённых файлов и для скрипта из `dist/index.html`;
   при необходимости открыть страницу в Chromium (Playwright), учитывая, что вне
   портала BX24 SDK недоступен и календарь будет пустым.
5. Разработка ведётся в ветке `claude/vibe-app-project-yv048o`; коммиты — на русском,
   кратко и по делу; пуш `git push -u origin claude/vibe-app-project-yv048o`.
   PR создавать только по просьбе пользователя.

## Битрикс24 / REST

- Режим по умолчанию `transport: 'bx24'` — `BX24.callMethod`, авторизация через портал.
- `transport: 'gateway'` — standalone через `https://vibecode.bitrix24.tech`
  с Bearer-ключом из `CONFIG.gateway.accessKey`.
- Scope: `user`, `task`, `calendar`. Методы: `user.get`, `tasks.task.list/add/update`,
  `task.elapseditem.getlist`, `calendar.event.get/add/update`, `BX24.appOption`.
- Задачи на сетке — по `START_DATE_PLAN…END_DATE_PLAN`, иначе 30 мин до `DEADLINE`.
  Часы: п = `TIME_ESTIMATE`, ф = `TIME_SPENT_IN_LOGS`, с = записи за сегодня.
- Отсутствия — события календаря с `accessibility: 'absent'`, встречи — `busy`.
- Данные недели грузятся одним batch-запросом; сохранять это при доработках.

## Безопасность

- Ключ `vibe_app_local_…` — секрет. Не выводить его в логи, тосты, комментарии,
  коммит-сообщения и этот файл. Не отправлять никуда, кроме шлюза vibecode.
- Ключ уже лежит в `js/config.js` и попадает в `dist/index.html`. Не размножать его
  по другим файлам; если пользователь попросит убрать ключ из репозитория — вынести
  в конфиг вне git и напомнить о перевыпуске ключа.
