# Планировщик для Битрикс24

Приложение-календарь (планировщик) для портала Битрикс24. Понедельная сетка
ПН–ПТ с 8:00 до 18:00 (шаг 30 минут), многоколоночный показ до 5 сотрудников,
работа с **Задачами**, **Встречами/Событиями** и **Отсутствиями** напрямую через
REST API Битрикс24.

Реализовано на чистом JavaScript (ES-модули) — **без сборки и зависимостей**.

## Возможности

- **Недельная сетка** ПН–ПТ, 8:00–18:00, слот 30 мин (≈50px), час ≈100px.
- **Навигация** по неделям («‹», «›», «Сегодня»); при запуске открывается текущая.
- **Мультиселект сотрудников** (до 5) в шапке + поиск; список из `user.get`.
- **Сохранение выбора** в настройках приложения (`BX24.appOption`) — подгружается
  при каждом запуске. Без выбора — подсказка «Выберите сотрудников для отображения».
- **Настройки (⚙)** — попап с выбором сотрудников по умолчанию и кнопкой «Сохранить».
- **Многоколоночная верстка**: 1 сотрудник — на всю ширину, 2–5 — столбцы
  (при 3+ появляется горизонтальный скролл).
- **Цвета**: задачи — голубой, встречи — зелёный, отсутствия — серый.
- **В ячейке задачи**: название (сокращается) + строка часов `ф:6/п:8/с:2`
  (факт / план / сегодня) + иконка статуса (ждёт ⏳, выполняется ▶, отложена ⏸,
  завершена ✓, просрочена ⚠).
- **Дублирование** общих встреч по столбцам сотрудников.
- **Клик по пустому слоту** → меню: создать задачу / выбрать существующую /
  создать встречу / добавить отсутствие.
- **Редактирование**: двойной клик по блоку или иконка «карандаш» при наведении.
- **Тултипы** с полной информацией (название, часы, статус, описание).
- **События вне сетки** (до 8:00 / после 18:00) прижимаются к краю и помечаются
  «↑ до сетки» / «↓ за сеткой».
- **Обработка ошибок**: понятные тосты + повторные попытки при сетевых сбоях.

## Структура

```
index.html            — точка входа, подключает BX24 JS SDK
css/styles.css         — стили (Material-минимализм)
js/
  config.js            — константы, цвета, статусы, режим транспорта
  dates.js             — работа с датами и RU-форматирование
  b24.js               — транспорт к Битрикс24 (BX24 SDK / шлюз), ретраи, батч, опции
  data.js              — доменный слой: загрузка/сохранение, маппинг в модель item
  state.js             — состояние приложения + шина перерисовки
  bus.js               — мост для перезагрузки (без циклических импортов)
  app.js               — bootstrap и связывание UI
  ui/
    calendar.js        — рендер сетки, ячеек, геометрии блоков
    employees.js       — мультиселект и попап настроек
    modals.js          — меню слота и формы создания/редактирования
    tooltip.js         — тултипы
    toast.js           — уведомления
```

## Запуск и установка в Битрикс24

Приложение встраивается в портал как **placement-приложение** и работает через
`BX24.callMethod` — отдельный ключ при этом не нужен, авторизацию обеспечивает
портал внутри iframe.

1. Раздайте файлы по HTTPS (любой статический хостинг). ES-модули требуют
   именно `http(s)://`, открыть `index.html` как `file://` нельзя. Для локальной
   проверки: `npx serve .` или `python3 -m http.server`.
2. В Битрикс24: **Разработчикам → Другое → Локальное приложение** (или через
   `placement.bind`). Укажите путь к приложению (URL вашего хостинга) и права:
   `task`, `calendar`, `user`.
3. Откройте установленное приложение — загрузится текущая неделя.

### Необходимые права (scope)
`user`, `task`, `calendar`.

### Используемые REST-методы
`user.get`, `tasks.task.list`, `tasks.task.add`, `tasks.task.update`,
`task.elapseditem.getlist`, `calendar.event.get`, `calendar.event.add`,
`calendar.event.update`, `app.option.get/set` (через `BX24.appOption`).

## Standalone-режим через шлюз vibecode (опционально)

Если нужно запускать приложение вне портала и обращаться к шлюзу
`https://vibecode.bitrix24.tech`, в `js/config.js` переключите
`transport: 'gateway'` и укажите ключ в `gateway.accessKey`. Весь HTTP-контракт
шлюза (пути `/v1/call`, `/v1/batch`, заголовок `Authorization: Bearer …`)
сосредоточен в `js/b24.js` — если фактический формат эндпоинта отличается, его
достаточно поправить в одном месте.

> ⚠️ **Безопасность:** ключ `vibe_app_local_…` — это секрет. Не публикуйте его в
> открытых репозиториях и не используйте gateway-режим во фронтенде, доступном
> неавторизованным пользователям (ключ виден в коде страницы). Для продакшена
> предпочтителен встраиваемый режим `bx24`.

## Замечания по реализации

- **Размещение задач на сетке**: по плановым датам `START_DATE_PLAN…END_DATE_PLAN`,
  иначе 30-минутный блок до `DEADLINE`. «Привязать задачу к слоту» проставляет
  плановые даты через `tasks.task.update`.
- **Часы**: `п` = `TIME_ESTIMATE`, `ф` = `TIME_SPENT_IN_LOGS`, `с` — сумма записей
  `task.elapseditem.getlist` за сегодня.
- **Отсутствия** — события календаря с `accessibility: 'absent'`; встречи — `busy`.
- **Производительность**: данные недели по всем сотрудникам грузятся одним батчем;
  блоки позиционируются абсолютно, пересекающиеся раскладываются по «дорожкам».
